# Juntas IT-Community — Descargas

Releases públicas de la app **Juntas** (Android · iOS · Windows · macOS).

- Descarga la última versión en la pestaña **Releases**.
- `version.json` / `appcast.xml` alimentan las auto-actualizaciones.
- `portals.json` es el directorio de portales que consume la app.

El código fuente vive en el repo privado `mavksoft/juntas-it-community`.
